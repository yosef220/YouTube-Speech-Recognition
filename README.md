# 🎤 חיפוש שיר בקול — Voice Song Search

לחצו על כפתור, **אמרו או שירו** מילים מתוך שיר, והאפליקציה תפתח לכם **ישירות בדפדפן את הסרטון המדויק ביוטיוב** (`youtube.com/watch?v=…`).

בדומה לחיפוש-בזמזום של YouTube ו-Shazam — אבל **חינמי, ללא התקנה, וללא שרת**. אפשר לארח בחינם ב-GitHub Pages.

---

## איך זה עובד

| מצב | מה עושים | הטכנולוגיה |
| --- | --- | --- |
| 🗣️ **אמירת מילים** | אומרים/שרים שורה מהשיר | דיבור→טקסט דרך **Web Speech API** של הדפדפן. את הסרטון המדויק ביוטיוב משיגים דרך שרתי **Piped/Invidious** ציבוריים (ללא מפתח) ופותחים ישירות. |
| 🎵 **זמזום / שירה** | מזמזמים מנגינה | מקליט אודיו ושולח ל-**AudD** לזיהוי (דורש מפתח חינמי — ראו למטה). |

> **על זיהוי זמזום בכנות:** זיהוי מנגינה אמיתי מזמזום (כמו ב-YouTube/Shazam) מבוסס על מודלים מאומנים ותשתית ענן — אין דרך *באמת חינמית ובלי שרת* לעשות זאת מאפס. לכן מצב "אמירת מילים" הוא הדרך החזקה והחינמית לגמרי, ומצב הזמזום מתחבר לשירות חיצוני אופציונלי.

---

## הרצה מקומית

זהו אתר סטטי — אין צורך בבנייה. רק צריך להגיש אותו מ-HTTP (מיקרופון לא עובד מ-`file://`):

```bash
# פייתון
python3 -m http.server 8000
# ואז פתחו:  http://localhost:8000
```

או כל שרת סטטי אחר (`npx serve`, Live Server ב-VS Code וכו').

עובד הכי טוב ב-**Chrome / Edge** (זיהוי דיבור). בכל דפדפן אפשר להקליד ידנית ולחפש.

3. האתר יעלה בכתובת `https://<user>.github.io/<repo>/`.

## הגדרות אופציונליות (⚙️)

הכול נשמר **מקומית בדפדפן בלבד** (localStorage). האפליקציה עובדת גם בלי אף מפתח.

- **מפתח YouTube Data API** — לדיוק גבוה יותר בתוצאות. השיגו חינם ב-[Google Cloud Console](https://console.cloud.google.com/) (הפעילו "YouTube Data API v3"). יש מכסה יומית חינמית.
- **מפתח AudD** — להפעלת זיהוי הזמזום. הירשמו ב-[audd.io](https://audd.io/) (יש שכבת ניסיון חינמית).

בלי מפתחות, מצב "אמירת מילים" עדיין עובד במלואו דרך שרתי Piped/Invidious הציבוריים.

## פרטיות

הכול רץ בדפדפן שלכם. אין שרת משלנו. חיפושי טקסט נשלחים לשרתי Piped/Invidious הציבוריים (או ל-YouTube API אם הגדרתם מפתח); אודיו נשלח ל-AudD רק אם בחרתם להשתמש במצב זמזום עם מפתח.
