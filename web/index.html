הגדרות ומידע

ברירת המחדל עובדת בלי שום מפתח, דרך מופעי Piped ציבוריים. הם נופלים לפעמים. למי שרוצה יציבות: הדבק כאן מפתח YouTube Data API v3 חינמי (10,000 יחידות ביום ≈ 100 חיפושים). המפתח נשמר בזיכרון הדף בלבד ונמחק ברענון.

כתובת שרת הזמזום (שלב 2). ברירת מחדל: http://localhost:8000. אם השרת פועל — מצב הזמזום ישלח אליו את ההקלטה ויקבל התאמה אוטומטית.

נדרש מיקרופון, ולכן הדף חייב לרוץ מעל https או localhost. זיהוי הדיבור עובד בכרום ובאדג'. מצב הזמזום דורש את שרת ה־Python משלב 2 בתוכנית.
